## Descrição dos Exercícios

A atividade consiste em 7 exercícios práticos focados em HTML5 estrutural e estilização com CSS3. Cada exercício está organizado em sua própria pasta contendo arquivos `.html` e `.css` separados.

### 1. Cartão de Visitas Digital (`exercicio-01`)
* **HTML**: Uso de `<h1>`, `<p>` para biografia e `<ul>` para links de redes sociais.
* **CSS**: Definição de cor de fundo, cor de texto e centralização dos elementos na tela.

### 2. Perfil de Personagem (`exercicio-02`)
* **HTML**: Título com o nome do personagem (Pikachu), imagem (`<img>`) e uma lista de suas principais habilidades.
* **CSS**: Largura fixa para a imagem com bordas arredondadas (`border-radius: 50%`) e fonte do texto personalizada (`font-family`).

### 3. Receita Simples (`exercicio-03`)
* **HTML**: Estrutura de uma receita de ovo frito utilizando `<h1>` para o título, `<ul>` para os ingredientes e `<ol>` para o modo de preparo.
* **CSS**: Espaçamento interno (`padding`) na página e cores personalizadas nas listas para se diferenciarem dos títulos.

### 4. Botão Estilizado (`exercicio-04`)
* **HTML**: Um link (`<a>`) com o texto "Clique Aqui" que direciona para o perfil do GitHub do desenvolvedor.
* **CSS**: Remoção do sublinhado padrão, definição de cor de fundo, cor de texto, espaçamento interno (`padding`) e efeito `:hover` para mudar a cor de fundo dinamicamente.

### 5. Bloco de Destaque / Card de Notícia (`exercicio-05`)
* **HTML**: Elemento `<div>` agrupando uma imagem de topo, título de notícia, data/autor e o parágrafo de conteúdo.
* **CSS**: Aplicação de cor de fundo distinta, borda fina com cantos arredondados (`border-radius`) e largura máxima (`max-width`).

### 6. Tabela de Preços Simples (`exercicio-06`)
* **HTML**: Uso da tag `<table>` com linhas (`<tr>`) e células (`<td>`/`<th>`) listando 3 produtos e seus preços.
* **CSS**: Bordas ao redor das células, cor de fundo escura no cabeçalho e alinhamento de texto centralizado.

### 7. Rodapé de Site / Footer (`exercicio-07`)
* **HTML**: Seção `<footer>` contendo texto de direitos autorais e um link de e-mail para contato.
* **CSS**: Rodapé fixado na parte inferior com cor de fundo escura, texto claro, alinhamento centralizado e espaçamento superior (`margin-top`).
